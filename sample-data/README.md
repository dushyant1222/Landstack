# Synthetic sample data

Everything here is generated by `generate_samples.py` (stdlib only, fixed seed). Names, identifiers,
registrations and coordinates are synthetic and do not describe real persons or parcels.

| File | Purpose |
|---|---|
| `bihar_parcels_sample.csv` | 38 rows, common column names (ULPIN, Khasra No, Owner Name, Area, Unit…). Deliberate problems: missing identifiers (row 5), negative area (row 7), latitude 95 (row 9), no coordinates (row 11), one coordinate (row 13), missing unit (row 15), ambiguous date `04/05/2019` (row 17), placeholders `N/A`/`-` (row 19), CSV-injection probe owner `=HYPERLINK(...)` (row 21), unit inside the value `12 acres` (row 23), `kanal` without a Bihar factor (row 25), 250000 ha (row 27), an identical repeated row and a same-ULPIN row with a different area (last two rows). Units include acre, bigha, katha, dhur, hectare, sq ft. |
| `bihar_parcels_revised.csv` | First five rows again with areas ×1.2 → cross-import duplicate and conflicting-area flags (not merged). |
| `rajasthan_khasra_register.xlsx` | Two sheets (`ReadMe`, `Khasra Register`) → sheet selection. Different vocabulary (Khasra/Survey No, Khatedar, Rakba, Bhumi Prakar, Gram, Tahsil, Zila, Lat/Long), `pucca bigha`/`kaccha bigha` and plain `bigha` (flagged: ambiguous in Rajasthan), Charagah/Gochar land types, some rows without coordinates. |
| `mutation_extract_sample.pdf` | Text-based 2-page PDF with `Label: value` lines → two candidate records with page references (needs the processing service). |
| `scanned_like_sample.pdf` | PDF with no text layer → reported as "OCR required — unsupported". |
| `performance_5000.csv` | 5,000 records for the performance check (20% without coordinates). |
| `invalid/` | `malformed_quotes.csv`, `pdf_renamed_as.csv` (signature mismatch), `header_only.csv` (no data rows), `notes.txt` (unsupported type). |

Regenerate: `python3 generate_samples.py`.
